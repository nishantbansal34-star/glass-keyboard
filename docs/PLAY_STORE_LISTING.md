# Google Play listing — Glass Keys

**App name:** Glass Keys — Glass Keyboard
**Short description (80):** Beautiful glass keyboard with smart suggestions, Hinglish & shop tools. Private.

**Full description:**
Glass Keys is a fast, beautiful keyboard made for India — with liquid-glass looks, smart suggestions and tools for shop owners. Everything stays on your phone: the app has no internet permission.

✨ Looks you'll love
• Liquid Glass, Immersive chrome glass, Soft Glass, Still (minimal) and Shadow Realm themes
• Glass keys that pick up your wallpaper's colours, smooth swipe trail

⌨️ Smart typing
• Next-word and whole-phrase suggestions ("let me check → and get back to you")
• Keyboard-aware autocorrect that learns — undo a fix once and it never repeats
• Swipe typing, emoji suggestions and emoji search
• Hindi keyboard and Hinglish → हिंदी typing ("aap kaise ho" → आप कैसे हो)

🛍️ Built for business
• One-tap UPI payment requests with QR code
• Price list, order builder and an order tracker (paid / delivered, day summary)
• Copy a customer's message ("kitne ka hai?", "kab tak aayega?") and get a ready reply
• Shop hours & location reply, quick texts, GST calculator

🔒 Private by design
• No internet permission — nothing you type can leave your phone
• Incognito mode, clipboard you control, backup to a file you choose
